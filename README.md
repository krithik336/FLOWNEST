# FlowNest

Welcome to **FlowNest**, a modern Project Management Tool built with React, Vite, Tailwind CSS, Express, and MongoDB.

## Repository Structure

- `frontend/` - React application styled with Tailwind CSS (Vite, React 19, Recharts).
- `backend/` - Node/Express API server connected to MongoDB Atlas.

## Getting Started

### 1. Set Up Backend
1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Configure your environment variables in `.env` (refer to `.env.example`).
4. Start the development server:
   ```bash
   npm run dev
   ```

### 2. Set Up Frontend
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
